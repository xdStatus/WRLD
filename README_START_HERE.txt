WRLD V18 — Native Windows player and update-ready build

Start with START_HERE_UPDATES.txt for the Windows EXE build and GitHub Releases setup.

Quick start: extract fully, run BUILD_WRLD_EXE.cmd, then run dist\WRLD.exe.

No songs are included or modified. The app uses your existing %%APPDATA%%\WRLDPlayer settings and playlists.

The update button is built into V18, but it requires your own published GitHub Releases repository before it can install future updates.
